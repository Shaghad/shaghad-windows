# SHAGHAD v0.5.0-beta.1 — First Windows Preview

Unsigned Development Pre-release. Production certification is pending.

## New features and improvements

- Original two-column VPN dashboard with a circular Connect/Disconnect control, left overlay navigation drawer and preserved native Windows caption controls.
- Real active-session duration, proxied exit IP and copy action, HTTPS-based application connectivity quality and up to three recently tested server candidates.
- Native Xray proxy-outbound and sing-box Clash API counters: current download/upload rates and totals for application-owned proxy traffic, including probes. Missing counters remain unavailable.
- Optional automatic failover in Auto mode: three consecutive failed checks, two attempts per user connection, two-minute cooldown and candidate exclusions. Disabled by default.
- Optional resume/network-change verification and bounded recovery. Disabled by default. Existing ConnectionService owns every start/stop.
- Explicit Diagnostics checks for IPv4/IPv6 remote exit availability; TLS validation remains enabled.

## Bug fixes

Duration uses monotonic time and supports sessions exceeding 24 hours. Telemetry loses its baseline on disconnect, restart, reset or missing samples. The dashboard clears exit IP when the active session stops. Existing core/proxy ownership and encrypted storage protections remain in place.

## Compatibility and limitations

Windows x64; .NET 10 self-contained portable distribution. Development-host validation is not clean-machine or Windows 10 certification. TUN and Kill Switch are not implemented. Local Proxy covers explicitly configured applications; System Proxy covers applications that honor Windows proxy settings. System Proxy always requires approval. Automatic recovery/failover with an owned System Proxy stops and attempts ownership-aware restoration; transferring ownership to a replacement listener is not validated and is blocked. External Windows proxy changes remain preserved.

Some protocols/transports/encryption require a compatible core; Xray ML-KEM VLESS Encryption cannot be translated to the pinned sing-box. Remote provider protocol coverage is not exhaustive. DNS bootstrap can use the local resolver; DNS leak protection is not certified. Quality is recent HTTPS request timing, not packet loss. Failover/recovery preferences are session-only and opt-in on each launch. Physical sleep/resume and full interactive accessibility need separate testing.

## Security and signing

No signing certificate is configured. Executable and package are unsigned; retain Windows security protections. Core binaries must match the compiled trust manifest. Xray exposes only StatsService on an ephemeral loopback port; this API lacks authentication and other local processes can read/reset its counters. Handler/routing/logger control APIs are disabled. sing-box uses a random session Bearer secret in private runtime configuration; requests use loopback with no ambient proxy, redirects or cookies. No telemetry payload, credentials or exit IP is logged.

Public redistribution remains subject to complete corresponding-source and dependency-license review; see legal notices. This local preview is not a complete compliance certification.

## Installation and upgrade

Verify `SHA256SUMS.txt`, extract `SHAGHAD-v0.5.0-beta.1-win-x64-portable.zip` into a new directory and run `Shaghad.exe`. No SDK or separate Desktop runtime should be required. Import your own authorized profile. No connection or Windows network changes happen on install/startup.

Close the old version before upgrading. User data remains in `%LOCALAPPDATA%\VPN-AJ`; do not replace or remove it. The installer script uses a stable application ID and per-user directory, optional desktop shortcut and uninstall support; it never deletes this data. An installer executable is available only when successfully compiled and validated.

```powershell
./scripts/verify-checksums.ps1 -Directory ./artifacts/releases/v0.5.0-beta.1
# Or verify one downloaded ZIP:
Get-FileHash ./SHAGHAD-v0.5.0-beta.1-win-x64-portable.zip -Algorithm SHA256
```
