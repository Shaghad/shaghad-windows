# SHAGHAD Phase 4 — Servers page

The existing shell, navy/turquoise identity, native caption, English/Persian resources and import editor are preserved. The Servers page now fills its allocated content area with a compact manager: total count, search/add/clipboard/test/sort toolbar, pinned Auto policy card, filters, test progress and a recycling list. Import clipboard opens the editor for review; raw share links never appear in the browsing page.

`Controls/ServerRowView.xaml` is the reusable 72-DIP row. It displays a bundled colored flag or neutral globe, an ellipsized profile name, protocol/core, actual HTTPS latency, health indicator, selected border, favorite action, Connect and a secondary action menu. Test details and last-tested time are tooltips. Unknown/failed results have no numeric latency. Failed, timeout, degraded, unsupported, testing and untested states remain distinct. The row Connect action asks before disconnecting an established session. Selection/removal/core/import operations remain guarded by the existing idle workflow.

Servers is a sibling of the normal page ScrollViewer, with a finite Grid `*` viewport and its own virtualized ListBox. There is no outer scrolling parent around the list. Collection replacement sends one Reset notification; row objects are reused by stable IDs. Measured results remain in memory and do not cause encrypted writes. English and Persian update through the existing language dictionary swap; the shell/sidebar/chrome remain LTR and text islands can use RTL.

## Flags

The PNGs under `apps/windows/AJ.VPN.Desktop/Assets/Flags` are 64×48 renders of two-letter assets from [flag-icons 7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2), licensed under MIT by Panayiotis Lipiridis. The complete license is `docs/legal/FLAG-ICONS-LICENSE.txt`, copied into published legal notices. Reproduction uses the npm 7.3.2 archive and `scripts/export-flags.cjs` with Sharp. The neutral globe is original vector artwork.

Flags represent explicit country metadata only. The Set Country editor accepts a user-verified ISO code or blank. No hostname/name heuristic or online geolocation request exists. A flag emoji in a provider remark is not used as location evidence.

## Actual WPF validation

The opt-in smoke harness uses isolated encrypted storage and visibly named OFFLINE UI fixtures. It captures real shown windows using PrintWindow; no screenshot is generated by an image model. The matrix covers 1024×600, 1280×720, 1366×768 and 1920×1080, Light/Dark and English/Persian. It checks viewport allocation, toolbar bounds, scrolling, row recycling, country search, favorites and actual Test All cancellation. At 100/500/1000 profiles the initial viewport realized six rows in the executed matrix. Counts depend on size and DPI.

Evidence and limitations are detailed in `docs/testing/SERVER-SELECTION-VALIDATION.md`. Native caption interactions, Narrator, other DPI values and long-running memory profiling are not certified by the automated captures.
