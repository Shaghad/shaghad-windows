# SHAGHAD brand identity

Date: 2026-10-11. Product: **SHAGHAD | شغاد**, **Modern Secure Network Client**.

The identity pairs a geometric Persian sheen with quiet desktop typography. The open bowl and connected teeth express a continuous path; three dots provide recognition without an illustrative historical motif. The literary name is an origin, not an endorsement of the character's conduct. No portrait or symbolism implying that Shaghad was a guardian is used.

Brand behavior: clear state, readable language, restrained accent use and honest availability. The current development application cannot establish a VPN connection, so its dashboard shows Disconnected, unavailable controls and em dashes for missing telemetry. Brand presentation must never be used as proof of security or a connected state.

The navy/turquoise core palette is preserved. Accessible light-surface variants add deep teal and a darker secondary text color. Green and red remain semantic status colors. The full palette, usage rules and numerical contrast results are in `D:\VPN-AJ\branding\BRAND-GUIDELINES.md` and `D:\VPN-AJ\branding\contrast-report.json`.

English uses Windows Segoe UI; Persian uses bundled Vazirmatn. The logo wordmark uses original vector paths, so another platform needs no installed font to display the identity. The UI uses Segoe UI for the English SHAGHAD name and Vazirmatn for Persian text. Do not replace a readable interface font with the logo lettering.

The font source is [the official Vazirmatn v33.003 release tree](https://github.com/rastikerdar/vazirmatn/tree/v33.003). Its [SIL OFL 1.1 license](https://github.com/rastikerdar/vazirmatn/blob/v33.003/OFL.txt) permits bundling under its conditions. The unmodified license and authors are retained in `D:\VPN-AJ\branding\fonts\`. The fonts are resources using the WPF approach described in [Microsoft's font packaging documentation](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/packaging-fonts-with-applications). Segoe UI is referenced from Windows and is not copied into this repository.
