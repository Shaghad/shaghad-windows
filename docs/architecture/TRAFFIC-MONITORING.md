# Owned-core traffic monitoring

Application-owned proxy traffic, including connectivity/IP probes, is measured. This is not all-device traffic. The generated single `proxy` outbound and private runtime session identify the scope; unrelated system network counters are never used.

Xray 26.3.27: private configuration adds `stats`, outbound uplink/downlink policy and simplified ephemeral IPv4 loopback API with only `StatsService`. The verified executable queries exact `outbound>>>proxy>>>traffic>>>` counters with a two-second command timeout and no reset. Other control APIs are absent. This native API lacks authentication; other local processes can read/reset counters. No profile/config retrieval or pprof endpoint is enabled. Source references: [API](https://xtls.github.io/en/config/api.html), [statistics](https://xtls.github.io/en/config/stats.html).

sing-box 1.14.3: ephemeral IPv4 loopback Clash API with per-session random 256-bit Bearer secret, no external UI/download, private configuration ACLs, restricted CORS. `/connections` supplies aggregate upload/download totals. Raw connection metadata is discarded, never displayed/persisted; response bounded to 1 MB, so excessive active-connection metadata makes telemetry unavailable. [Configuration reference](https://sing-box.sagernet.org/configuration/experimental/clash-api/).

Each read checks that the native listener belongs to the active owned PID; late reads are discarded after session changes. Xray's executable remains hash-verified and held open. Native interfaces were tested with both pinned binaries. Telemetry samples occur no faster than every two seconds, sequentially, with no overlapping monitor operation. Rates use `TimeProvider.GetTimestamp()` elapsed monotonic differences. First samples have totals but unavailable rates. Reset, negative values, overflow, missing samples and core restart break the baseline. Disconnect clears displayed counters immediately. Polling stops during suspend/shutdown. No traffic history is persisted.
